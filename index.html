Bulk Exporter for Jira

Export Jira issues to PDF, Excel and CSV. No 1,000-issue limit. Tables, panels, formatting and attachments come through intact.

Runs on Atlassian. The app uses only Atlassian-hosted compute and storage and declares no external network egress. Your issue data never leaves Atlassian's cloud.

What it does

  • No issue cap. Jira's built-in export stops at 1,000 issues. This one does not stop.
  • Faithful PDF. Rich text, tables, panels, code blocks, lists, mentions and images are rendered, not flattened to plain text.
  • Attachments included. Images embedded in a description are rendered in place; every other attachment is listed with its name, type and size.
  • Excel and CSV. One row per issue, with autofilter, sensible column widths and a UTF-8 byte order mark so accented characters survive in Excel.
  • Japanese, Chinese and Korean are rendered with an embedded font instead of turning into unreadable characters.
